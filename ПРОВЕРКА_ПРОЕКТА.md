### ❌ Критические Проблемы

#### Проблема #1: Firebase НЕ Используется
**Файл: `src/App.tsx`**

Сейчас:
```typescript
const [users, setUsers] = useKV<User[]>('users', [])  // localStorage!
const [orders, setOrders] = useKV<Order[]>('orders', [])  // localStorage!
```

Должно быть:
```typescript
// Данные из Firebase Firestore с real-time обновлениями
```

**Последствия:**
- ❌ Все данные хранятся в браузере (localStorage)
- ❌ Данные не синхронизируются между устройствами
- ❌ Админ и пользователь видят РАЗНЫЕ данные
- ❌ Нет безопасности данных
- ❌ Любой может изменить localStorage в DevTools

#### Проблема #2: Аутентификация Не Использует Firebase
**Файл: `src/components/Auth.tsx`**

Сейчас:
```typescript
const user = users.find(u => 
  u.finCode === loginFin && 
  u.password === loginPassword  // Пароли в открытом виде!
)
```

Должно быть:
```typescript
await authService.login(email, password)  // Firebase Auth
```

**Последствия:**
- ❌ Пароли хранятся в открытом виде
- ❌ Нет шифрования
- ❌ Нет защиты от взлома
- ❌ Логин не безопасен

#### Проблема #3: Нет Real-Time Обновлений

Сейчас данные загружаются один раз. Если админ изменит статус заказа, пользователь **не увидит** изменения без перезагрузки страницы.

Должно быть: Real-time listeners с `onSnapshot()`

### Текущая Архитектура (НЕПРАВИЛЬНО)
```
Пользователь → React → localStorage (браузер)
                    ↓
            Firebase НЕ используется
```

### Правильная Архитектура
```
Пользователь → React → Firebase Auth → Аутентификация
                    ↓
                Firebase Firestore → База данных
                    ↓
            Real-time синхронизация
```

## Детальный План Исправлений

### Шаг 1: Создать `.env` файл
```bash
cp .env.example .env
```

Заполнить вашими Firebase credentials:
```
VITE_FIREBASE_API_KEY=ваш_ключ
VITE_FIREBASE_AUTH_DOMAIN=ваш_проект.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=ваш_проект
VITE_FIREBASE_STORAGE_BUCKET=ваш_проект.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=ваш_id
VITE_FIREBASE_APP_ID=ваш_app_id
```

### Шаг 2: Создать Firebase Проект
1. Перейти на https://console.firebase.google.com/
2. Создать новый проект
3. Включить Email/Password Authentication
4. Создать Firestore Database
5. Скопировать credentials

2. `src/components/Auth.tsx` - Интегрировать Firebase Auth

4. `src/components/AdminPanel.tsx` - Использовать Firebase сервисы
